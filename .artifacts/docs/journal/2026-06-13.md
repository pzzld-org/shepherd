## Decision: #12 (safe simplification) — DECLINED the profile-surgery
The handoff's survey listed ~122 lines of "behavior-neutral" brief-dedup. On
close inspection the candidates do NOT survive the behavior-neutral bar:

- **"NEVER write source code"** is role-tuned, not verbatim — conductor scopes
  to `.md` + auditor-completeness catch; engineer scopes to artifacts dirs +
  `git log --author` grep + C+ grade-cap + commit-origin note; planter scopes
  to the source tree. Each prohibition is concrete and self-enforcing IN
  CONTEXT. A "shared base + per-role exceptions" would force a second read and
  strip the role-specific enforcement detail.
- **Specialist-dispatch rule** is already DRY through
  `doctrines/specialist-dispatch.md`; the profiles carry role-specific
  summaries (conductor: full rule #3 + sub-bullets; shepherd: two halt-code
  rows) that point at the shared doctrine. Correct factoring already.
- **Halt-code tables** are largely DISJOINT role vocabularies (conductor ~24
  dispatch/mode/gate codes; shepherd ~12 root-coordination; planter ~10
  planting). Not redundant tables to merge — relocating them out of the
  profiles would force every agent to read a reference to resolve its own codes.

These dense system-prompt profiles deliberately reinforce critical rules at the
decision point — that is prompt engineering, not accidental duplication.
Collapsing them is a net negative for a cosmetic line-count win, and directly
contradicts the handoff guardrail ("Plugin is WELL-FACTORED — simplify only via
shared-reference extraction; don't over-refactor or merge separated doctrines").
Budget redirected to #10 (toggles) and #9 (axiom scrub), which deliver real
capability + project-agnosticism. If a future session wants line reduction, the
sound target is genuinely-verbatim blocks (none found in this pass), not the
role-tuned reinforcement.
